# Quote Generator 2.0

A simple quotation generation tool built for a Vietnam-based Destination Management Company (DMC).

I developed a clean index page that helps the operations team generate quotations based on different customer queries and travel requirements.

### Features
- **Dynamic Quotations:** Generate quotations based on different travel requirements.
- **Copy as Table:** Copy quotations in a structured tabular format, ready to paste into emails or documents.
- **Download Voucher:** Download the generated voucher easily.

### Purpose
To make quotation preparation simpler, faster, and more organised for daily tour operations.

**Version:** 2.0
